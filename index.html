0 · Resumen: qué se hizo

Este simulador muestra cómo se distribuye y cómo se mueve el campo electromagnético dentro de una guía de onda rectangular. Hay dos familias de modos:

TE (Ez = 0):   Hz = H₀ cos(nπx/a) cos(mπy/b) e−γz ejωt   con n, m = 0, 1, 2, …

TM (Hz = 0):   Ez = E₀ sen(nπx/a) sen(mπy/b) e−γz ejωt   con n, m = 1, 2, 3, …

Las tarjetas de abajo explican de dónde sale cada una de estas ecuaciones y cada número que se calcula. El programa sigue cuatro pasos:

  1. Calcula las constantes del modo: kx, ky, kc, fc, β y λg.
  2. Evalúa el patrón del campo en una malla de puntos dentro de la guía.
  3. Lo multiplica por el factor de propagación y de tiempo, cos(ωt − βz).
  4. Convierte el resultado (un valor entre −1 y 1) en color y lo dibuja en 3D, en la sección x–y y en el corte z–x.
Cómo leer los colores y los dibujos
  • Cian: el campo es negativo en ese punto. Magenta: es positivo. Cuanto más intenso el color, mayor es la amplitud.
  • Oscuro: el campo vale cero. Las franjas oscuras son los nodos del modo.
  • El color muestra la componente longitudinal: Hz en TE y Ez en TM.
  • Las flechas blancas son el campo eléctrico transversal Et.
  • Línea verde punteada: posición y₀ del corte. Línea magenta: posición z₀ de la sección.
1 · Geometría y suposiciones
  • Guía rectangular de lados a (eje x, 0 ≤ x ≤ a) y b (eje y, 0 ≤ y ≤ b). La onda viaja en z.
  • Paredes de conductor perfecto: el campo eléctrico tangencial a la pared vale cero.
  • Interior vacío (ε₀, μ₀) y sin fuentes (sin cargas ni corrientes).
  • Régimen senoidal: todo depende de ejωt, y en z de e−γz.
2 · Ecuación de onda (Helmholtz)

Maxwell sin fuentes con ejωt:

∇×E = −jωμH   ∇×H = jωεE

Tomando el rotacional de una y sustituyendo la otra:

∇²ψ + k²ψ = 0,   k = ω√(με) = ω/c = 2π/λ

Con dependencia e−γz, la derivada ∂²/∂z² se vuelve γ². Para la componente longitudinal ψ (Hz o Ez):

∂²ψ/∂x² + ∂²ψ/∂y² + (γ² + k²) ψ = 0

Se define el número de onda de corte: kc² = γ² + k².

3 · Modo TE: separación de variables

En TE, Ez = 0 y la incógnita es Hz. Proponemos Hz = X(x)·Y(y)·e−γz. Sustituyendo y dividiendo entre XY:

X″/X + Y″/Y + kc² = 0

Cada término depende de una sola variable, así que cada uno es constante:

X″ = −kx² X,   Y″ = −ky² Y,   kx² + ky² = kc²

Soluciones: X = A cos(kxx) + B sen(kxx), y lo mismo para Y.

4 · Modo TE: condiciones de frontera

El campo eléctrico tangencial debe anularse en las paredes. Con las ecuaciones de Maxwell, Ey ∝ ∂Hz/∂x y Ex ∝ ∂Hz/∂y. Entonces:

X′(0) = X′(a) = 0,   Y′(0) = Y′(b) = 0

X′ = −kxA sen(kxx) + kxB cos(kxx). Con X′(0) = 0 sale B = 0 (queda coseno). Con X′(a) = 0 se necesita sen(kxa) = 0, o sea:

kx = nπ/a,   ky = mπ/b,   n, m = 0, 1, 2, …

Hz = H₀ cos(nπx/a) cos(mπy/b) e−γz

n = 0 o m = 0 sí está permitido (el coseno vale 1, no es solución trivial), pero no ambos a la vez, porque Hz sería constante y no habría campo transversal.

5 · Modo TM

En TM, Hz = 0 y la incógnita es Ez = X·Y·e−γz. La separación es idéntica, pero ahora Ez es tangencial a las paredes, así que:

Ez = 0 en x = 0, a y en y = 0, b ⇒ X(0) = X(a) = 0, Y(0) = Y(b) = 0

X(0) = 0 elimina el coseno (queda seno), y X(a) = 0 da kx = nπ/a. Igual para y:

Ez = E₀ sen(nπx/a) sen(mπy/b) e−γz,   n, m = 1, 2, 3, …

Aquí n = 0 o m = 0 da Ez ≡ 0, por eso en TM se empieza en 1. El primer modo TM es TM11.

6 · Frecuencia de corte, β y λg

De kc² = γ² + k² y kc² = (nπ/a)² + (mπ/b)²:

γ² = kc² − k²

  • Si k > kc: γ = jβ, hay propagación.
  • Si k < kc: γ = α real, la onda decae (evanescente).

El límite es k = kc, que da la frecuencia de corte:

fc = c·kc/(2π) = (c/2)·√((n/a)² + (m/b)²)

β = √(k² − kc²) = k·√(1 − (fc/f)²),   λg = 2π/β = λ/√(1 − (fc/f)²)

λg siempre es mayor que λ. El modo dominante (menor fc) es TE10 cuando a > b. La razón f/fc del panel debe ser mayor que 1.

7 · Campos transversales (las flechas)

De Maxwell, todos los campos transversales salen de la componente longitudinal:

TE: Et = −(jωμ/kc²) ẑ × ∇tHz

TM: Et = −(γ/kc²) ∇tEz

Derivando Hz y Ez (salvo constantes):

TE: Ex ∝ (mπ/b) cos(nπx/a) sen(mπy/b),   Ey ∝ −(nπ/a) sen(nπx/a) cos(mπy/b)

TM: Ex ∝ (nπ/a) cos(nπx/a) sen(mπy/b),   Ey ∝ (mπ/b) sen(nπx/a) cos(mπy/b)

El programa divide entre kc para que la flecha más larga mida 1, y las multiplica por sen(ωt − βz): el factor j significa que Et va desfasado 90° respecto a Hz o Ez.

8 · Del fasor a la animación

El campo real es la parte real del fasor. Con γ = jβ:

Hz(x,y,z,t) = Re{H₀ cos(nπx/a) cos(mπy/b) ej(ωt − βz)} = H₀ cos(nπx/a) cos(mπy/b) cos(ωt − βz)

  • El patrón en x e y es fijo (estacionario); solo la parte cos(ωt − βz) se mueve.
  • Los máximos cumplen ωt − βz = constante, así que avanzan con velocidad de fase vp = ω/β (mayor que c).
  • Sección x–y: z = z₀ fijo, el patrón respira con cos(ωt − βz₀).
  • Corte z–x: y = y₀ fijo, se ve el patrón de x multiplicado por una onda que viaja en z.
  • En el código, phase es ωt y crece con el tiempo.
9 · Qué hace el código, paso a paso
  1. params() lee a, b, n, m y f/fc, y calcula kx, ky, kc, fc, f, k, β y λg.
  2. Revisa que el modo exista (TE: no n = m = 0; TM: n, m ≥ 1).
  3. Define la escala en píxeles por mm y guarda en una malla el patrón scalar(x,y), el cos·cos o sen·sen.
  4. En cada cuadro suma al tiempo, multiplica la malla por cos(ωt − βz) y lo convierte en color: cian negativo, oscuro cero, magenta positivo.
  5. Dibuja la sección, el corte y la vista 3D (esas imágenes se pegan sobre planos con una transformación afín). Después dibuja paredes, cotas y flechas.

12 · ¿Por qué a veces el corte sale vacío? (nodos del campo)

El corte z–x se hace en y = y₀. En TE21, Hz ∝ cos(2πx/a) cos(πy/b). Con y₀ = b/2, cos(π/2) = 0, así que Hz = 0 en todo el plano y no se ve nada. Es un nodo del campo, no un error. Mueve y₀ hacia 0 o 1. Pasa en TE con m impar y en TM con m par. También hay nodos en x: cos(nπx/a) se anula en n posiciones (TE) y sen(nπx/a) en n − 1 posiciones interiores (TM), y esas líneas se ven como franjas oscuras en la sección.
